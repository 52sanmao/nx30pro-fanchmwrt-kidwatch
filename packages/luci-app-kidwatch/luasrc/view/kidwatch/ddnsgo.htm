<%+header%> <% -- DDNS-Go 不在固件里，是从 GitHub release 直接装的二进制（/usr/bin/ddns-go）， -- 自带一个 http 管理界面（默认 9876）。这里只做两件事： -- ① 把「进程活没活 / 解析到哪个 IP / 外网该用哪个地址」摆出来，省得每次进去翻； -- ② 给一个入口跳过去。不做 iframe：LuCI 是 https，ddns-go 只有 http， -- 混在 https 页面里会被浏览器按混合内容拦掉。 local function sh(cmd) local f = io.popen(cmd .. " 2>/dev/null") local s = f and f:read("*a") or "" if f then f:close() end return (s or ""):gsub("%s+$", "") end -- pidof 按 /proc//comm 精确匹配；pgrep -x 在这版 busybox 上 -- 实际是按整条 cmdline 比，永远匹配不上，会误报「未运行」。 local pid = sh("pidof ddns-go"):match("^%d+") or "" local port = sh("uci -q get ddns-go.main.port") if port == "" then port = "9876" end -- 域名：config.yaml 是 ddns-go 自己写的，结构固定但缩进深， -- 用「domains: 之后连续的 - xxx 行」来收，遇到别的键就停，避免把 -- dns 段里的其它列表项当成域名。 local domains = {} local inDom = false for line in (sh("cat /etc/ddns-go/config.yaml") .. "\n"):gmatch("([^\n]*)\n") do if line:match("^%s*domains:%s*$") then inDom = true elseif inDom then local d = line:match("^%s*%-%s*([%w%._%-]+%.[%w%._%-]+)%s*$") if d then domains[#domains + 1] = d else inDom = false end end end -- WAN 侧 IPv6：eth1 上第一个 scope global 的地址，就是 ddns-go 用 -- 「通过网卡获取」会报上去的那个（也是现场出网用的源地址）。 local v6 = "" for line in (sh("ip -6 addr show dev eth1") .. "\n"):gmatch("([^\n]*)\n") do if v6 == "" then local a = line:match("inet6%s+([%x:]+)/%d+%s+scope%s+global") if a then v6 = a end end end %>

DDNS-Go

独立运行的小程序，负责把路由器当前的公网 IPv6 同步到 Cloudflare 域名上。

关于端口：IPv6 没有 NAT，但光猫和本机防火墙都会拦入站。当前已在防火墙放行 8443 （HTTPS 进 LuCI），80/443 保持关闭。如果外部访问不通，先确认光猫侧是否开了「IPv6 防火墙」， 再考虑换端口。
